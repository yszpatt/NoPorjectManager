# 记录怎么写

看板的价值全在文字上。目标读者是**三个月后的你自己**：一眼看懂这次做成了什么、改动了什么、卡在哪。

## 基本形式：结论 + 分条

```
<一句话结论>

1. 完成：…
2. 调整：…
3. 卡点：…
```

- **首行是结论**：一句话说清这次的结果，能带数字就带。卡片上只显示这一行
- 空一行，下面分条列
- 每条以**分类标签**开头，**一条只讲一件事**
- 不是所有标签都要用，有什么写什么；一两条就够时不必凑数

## 分类标签

| 标签 | 用于 | 例子 |
|---|---|---|
| `完成` | 做完的功能或产出 | `完成：项目增删改查与进展上报接口` |
| `调整` | 对已有功能的优化与改动 | `调整：卡片信息收敛到 5 条，次要字段收进详情页` |
| `修复` | 修掉的缺陷 | `修复：「多久没动过」天数偏大一天（时间戳混用偏移）` |
| `决策` | 方案取舍及理由 | `决策：提醒只保留「计划停滞」，进度落后不再提醒` |
| `卡点` | 阻塞与外部依赖 | `卡点：建表需 DBA 审批，未批前无法继续` |
| `问题` | 发现但尚未解决的 | `问题：跨域策略无条件放行，任意网页都能操作看板` |
| `验证` | 怎么确认没问题 | `验证：37 项走查测试全部通过` |
| `下一步` | 紧接着要做什么 | `下一步：审批通过前先推进不受影响的部分` |

顺序按上面表格排列：完成 → 调整 → 修复 → 决策 → 卡点 → 问题 → 验证 → 下一步。**卡点与问题如果会阻塞他人，提到最前面。**

## 口吻：汇报体

客观、简洁、名词化。不是聊天，也不是开发日志。

| ✗ 过于口语 | ✗ 过于机器 | ✓ 汇报体 |
|---|---|---|
| `看板上现在能分清哪些记录是 Agent 写的了，以前全记成「人工」，排查时会被误导` | `修复来源标记缺陷：REST 与 CLI 把 source 硬编码为 user，导致 Agent 写入被标成「人工」` | `修复记录来源标记错误<br>1. 问题：接口把来源硬编码为「人工」，Agent 写入被错误归类<br>2. 修复：支持显式声明来源，并对非法值回落校验` |
| `顺手把界面精简了一遍，现在卡片只留 5 条` | `界面按反馈精简：卡片固定 5 条信息，次要字段收进折叠区；进度可选自动跟随里程碑` | `按反馈精简界面，降低维护成本<br>1. 调整：卡片信息固定为 5 条，次要字段收进详情页<br>2. 调整：进度可切换为跟随里程碑自动计算，不必手工维护百分比` |

**口语要避免**：以 `了` 收尾的感叹、`其实` / `顺手` / `一堆` / `挺` / `反而`、把过程当故事讲。
**机器味要避免**：文件名、函数名、变量名、`feat(x):` 前缀、英文术语（写「表结构」不写 schema）、数字堆砌、结尾署名。

## 各类型的底线要求

| 类型 | 至少包含 |
|---|---|
| 进展 | 结论 + 1 条`完成` +（有就加）`问题`/`卡点` |
| 决策 | 结论（选了什么）+ 1 条`决策`（为什么） |
| 卡点 | 结论 + `卡点` + `影响` 或 `下一步` |
| 发布 | 版本 + 1–2 条`完成`，写**用的人能做什么** |

## 一句话也合法

单条提交、状态变更这类只承载一个事实的，保持一行即可，不要硬拆：

```
修复：收藏夹入口移到卡片页脚，修按钮重叠与弹窗被遮挡
```

## 长度

- 首行 ≤ 30 字
- 每条 ≤ 40 字
- 总计 3–5 条为宜，超过 6 条说明该拆成多条记录

## 禁止

- `优化` / `完善` / `推进` / `对齐` 这类没有宾语的空话
- 一条里塞多件事
- 只写做了什么、不写结果与影响
- 结尾署名、commit 前缀、英文标识符

## 写完自查

1. 只看首行，能知道这次的结果吗？
2. 每条都有分类标签、且只讲一件事吗？
3. 是汇报口吻，还是聊天 / 开发日志口吻？

## 示范

```
看板后台接口与四个视图完成，进入联调
1. 完成：项目、进展、计划、风险的读写接口
2. 完成：四个视图界面与项目详情抽屉
```

```
修复两个缺陷，均已验证
1. 修复：「多久没动过」的天数偏大一天（时间戳混用 UTC 与本地偏移）
2. 修复：任意网页都能操作看板（跨域策略无条件放行），现收敛到本机
```

```
阻塞：等待 DBA 审批建表
1. 卡点：新建表需 DBA 审批，未批下来前无法继续
2. 下一步：审批期间先推进不依赖新表的部分
```

```
v0.1 发布：Windows 桌面版可用
1. 完成：Windows 桌面包（原生窗口）与品牌标识
2. 说明：Docker 装法不受影响
```
