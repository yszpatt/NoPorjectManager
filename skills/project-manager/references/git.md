# Git 与看板的配合

## 一、提交怎么写

看板会把提交标题原样读进来当记录，所以**提交标题就是给人看的第一手材料**，和写记录同一个标准。

| 要求 | 说明 |
|---|---|
| 说清「解决了什么」 | `修好详情弹层顶出屏幕的问题` ✓ ／ `fix style` ✗ |
| 中文优先 | 看板按中文阅读，中英混杂的标题读起来费劲 |
| 一次提交一件事 | 标题里堆三件事，看板上就是一条读不完的记录 |
| 类型前缀可选 | `feat(web):` `fix(api):` 会被采集器自动剥掉，写不写都行——留着便于你自己 grep |
| 不要写署名 | `（张三）` 之类会被剥掉，作者已经单独记录在 `actor` 里 |

`[pm:项目id] +10` 的语义是**显式声明这次提交让进度前进/后退了多少**：

- 只在真的想改进度时才写，它不是装饰
- 写了之后**不要再**调用 `pm_report_progress` 累加同一个增量（会重复计数）
- 它会被采集器从标题里剥掉，不会显示在看板上
- 标签指向其它项目的提交，会被本项目的同步跳过，由对应项目自己的同步处理

## 二、提交和汇报不要重复（最重要）

同一件事既提交又汇报，看板上就刷出两行。**规则：一件事只留一条记录。**

| 情形 | 怎么做 |
|---|---|
| 一次提交就把事说清了 | **只提交，不用再汇报** |
| 一组提交构成一件事 | 汇报一次，带上全部提交：`refs: { commits: "sha1 sha2" }` |
| 提交标题表达不了「为什么」 | 汇报里补决策与背景，带上 `refs: { commit: "sha" }` |
| 提交和汇报时间隔得远 | 仍然显式带 `refs.commit`——显式关联不受时间限制 |

**为什么要带 `refs.commit`**：看板会按 sha 把提交并进汇报——看板上只显示你写的那条，提交以短 sha 徽章挂在旁边，点开能核对原始标题。

不带 sha 就要靠时间窗口猜：同项目、2 小时内、**一对一**才敢并。稍复杂一点（比如一小时内两次提交、两条汇报）就并不上，于是出现重复。**显式带上 sha 是唯一可靠的方式。**

## 三、自动合并的边界

- 只有**一对一**才自动合并；有多个候选一律不动。错并比不并更难发现
- 系统生成的审计事件（`状态 a → b`、`进度 x% → y%`）不参与，它们没有叙述可承载
- 发布记录不参与自动合并
- 合并只发生在**读取时**：事件流里两条原始记录都还在，`pm_timeline` 照旧能拿到
- 默认开启、窗口 2 小时；`git.autoLinkReports = false` 可关掉自动配对（显式 `refs.commit` 始终有效）

## 四、同步

```
pm_sync_git(project_id?)   # 扫描已关联仓库的 commit 与版本 tag
pm_link_repo(id, path)     # 关联本地仓库
```

- **幂等**：提交事件的 id 由完整 sha 派生，重复同步不会产生重复记录
- 采集到的提交默认**不改动进度**，只贡献活跃度；唯一例外是标题里的 `[pm:id] +N`
- 命名符合版本号规范的 tag 会被采集为**发布记录**（事件 id 为 `release-<tag>`，同样幂等）
- 会话结束的 hook 会自动同步一次；需要即时生效就手工调 `pm_sync_git`

## 五、完整示范

```bash
git add -A
git commit -m "feat(collections): 收藏夹支持整包导入"
```

```ts
// 提交标题已经说清了 → 什么都不用汇报
// 但要补充「为什么」和影响 → 汇报一次，带上提交 sha
pm_report_progress(
  id: "videorag",
  content: [
    "收藏夹支持整包导入",
    "",
    "1. 完成：一次可导入整个收藏夹的视频，不用逐个添加",
    "2. 调整：导入入口从卡片移到侧边栏，与其它导入方式并列",
  ].join("\n"),
  refs: { commit: "3f2a1b9" },
)
```

看板上的结果是一条记录，旁边挂着 `3f2a1b9` 的徽章：

```
13:17  进展  VideoRag  收藏夹支持整包导入                    3f2a1b9  Agent
                        1. 完成：一次可导入整个收藏夹的视频，不用逐个添加
                        2. 调整：导入入口从卡片移到侧边栏，与其它导入方式并列
```
